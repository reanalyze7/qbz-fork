# Canonical app icons

Canonical icon source for the `.deb` (packaging/nfpm/nfpm.yaml), which is the
only package this project ships. The hicolor PNGs below are what the deb
installs; the macOS `icon.icns` went with the dmg pipeline.

- `NNxNN.png` — hicolor sizes (32/48/64/128/256/512, plus `128x128@2x`)
- `icon.icns` — macOS bundle icon
